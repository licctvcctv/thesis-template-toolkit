                    摘   要
  随着网络攻击手段的复杂化，传统入侵检测系统在时序数据分析与深层特征提取上的
局限性日益显著。本文针对这一问题，设计并实现了一种基于长短期记忆网络（LSTM）与
自编码器（Autoencoder）融合的入侵检测模型。通过结合LSTM的时序依赖捕捉能力与自
编码器的无监督特征学习优势，构建双向特征学习框架，实现网络流量时序模式与高维特
征的双向建模。模型采用共享编码器参数与多任务学习策略，优化分类性能并提升训练效
率。
  实验基于NSL-KDD数据集，通过特征筛选、标准化预处理及分批次训练，采用Adam
优化器与交叉熵损失函数优化模型参数。测试结果表明，该模型在二分类任务中准确率达
到与多分类任务较传统方法与单一深度学习模型具有显著优势，尤其在异常流量检测中展
现出更高的鲁棒性与泛化能力。此外，模型通过自动特征提取减少了对人工特征工程的依
赖，验证了机器学习学习在入侵检测中的有效性。
     本文提出的方法为智能化入侵检测提供了新思路，但实际部署中仍需进一步优化硬件
适配性及实时响应效率。

                                           ABSTRACT
     With the increasing complexity of cyberattack techniques, traditional intrusion detection
systems face significant limitations in time-series data analysis and deep feature extraction. This
paper addresses this issue by designing and implementing an intrusion detection model based on
the fusion of Long Short-Term Memory (LSTM) networks and Autoencoders. By combining the
time-series dependency capturing capability of LSTM with the unsupervised feature learning
advantage of Autoencoders, a bidirectional feature learning framework is constructed to model
both network traffic time-series patterns and high-dimensional features. The model adopts shared
encoder parameters and a multi-task learning strategy to optimize classification performance and
improve training efficiency.
     The experiment is based on the NSL-KDD dataset, where feature selection, normalization
preprocessing, and batch training are conducted. The Adam optimizer and cross-entropy loss
function are used to optimize model parameters. Test results show that the model achieves higher
accuracy in binary classification tasks compared to traditional methods and single deep learning
models in multi-classification tasks, particularly demonstrating higher robustness and
generalization ability in detecting anomalous traffic. Moreover, the model reduces dependence on
manual feature engineering through automatic feature extraction, verifying the effectiveness of
machine learning in intrusion detection.
     The proposed method provides a new approach for intelligent intrusion detection, although
further optimization is needed in terms of hardware adaptability and real-time response efficiency
for practical deployment.


KEY WORDS: Intrusion Detection, LSTM, Autoencoder, NSL-KDD Dataset, Machine

                       第一章 绪论
1.1 背景和意义
  近年来，互联网连接服务迅速增加。据估计，到 2020 年，将有 500 亿台设备连接到
互联网。在数字化转型浪潮下，信息通信技术体系虽显著提升了社会运行效率，却也催生
出日益严峻的网络威胁生态。当前网络攻击手段正经历智能化演变，新型恶意代码采用多
态变形、零日漏洞利用等高级技术，使得传统防御体系面临严峻挑战。据统计，全球每年
因 IT 系统缺陷导致的经济损失已达百亿级规模，且呈现加速上升趋势，预计未来几年这一
数字还会增长。因此，网络安全已成为当代社会面临的首要挑战。为此，监控和分析网络
流量数据对于检测潜在攻击模式至关重要。在此背景下，为了开发更智能的入侵检测系统
(IDS，Intrusion Detection System)，以防止恶意威胁并确保更好的网络安全，全球科技企业
正加大数据科学投入，推动入侵检测系统向智能化演进。这个概念包括一组源自计算、统
计和信息技术的技术，包括众所周知的机器学习 (ML，Machine Learning) 方法。然而，不
同来源生成的大量异构大数据使得传统数据分析和浅层机器学习方法无法有效且不足以
直接应对此类安全挑战。值得注意的是，传统机器学习技术存在延迟和计算复杂性问题，
并且无法有效学习大数据集中存在的复杂且随时间变化的非线性关系。为了克服这些限制，
从而提高入侵检测性能，我们将传统数据分析和机器学习相结合。具体而言，我们结合深
度学习(DL，Deep Learning) 技术，开发出一种更有效的入侵检测系统 (IDS)。众所周知，
DL 算法能够通过分层学习过程自动从输入表示中提取高层次的抽象。深度学习在现实世
界的各个研究领域都取得了有趣的成果，如生物工程情绪分析图像识别和显著性检测。最
近，它也被用于开发入侵检测系统。

1.2 国内外研究现状
  近年来，有许多入侵检测系统使用基准 KDD99 和 NSL-KDD 数据集来评估 IDS
模型的性能和有效性。例如，Ingre 和 Yadav [1]开发了一个 3 层 MLP ，使用 NSL-
KDD 数据集检测攻击，多分类准确率达到 79.9%，二分类准确率达到 81.2% 。Ibrahim
等人[2]提出了一种基于自组织映射（SOM）的二分类新方法，并在 NSL-KDD 测试数据
集上报告了 75.49% 的检测准确率。Mohamed 等人[3]应用MLP等传统学习技术，通过将
数据集分成 10 折，二分类准确率达到 95.7%。高等人[4]开发了一种基于模糊和集成学习
理论的半监督学习方法，使用 NSL-KDD 数据集，在 KDD 测试集上的准确率为
84.54%。Alrawashdeh 等人[5]实现了一个基于限制玻尔兹曼机(RBM) 的深度信念网络

1.3 本课题主要工作
       传统 LSTM 网络虽能有效捕捉网络流量数据的时序依赖特性（如 TCP 连接状态的连
续性变化），但对高维特征的空间相关性建模能力有限。本课题通过引入自编码器
（Autoencoder）结构，构建了双向特征学习框架。
       本课题将 LSTM 模型和自编码器功能相结合，LSTM 处理时序信息，自编码器进行特
征提取，共享编码器输出，实现多任务学习。
       本课题的优势分析：
       （1）特征提取优势：自动学习特征表示、捕捉时序依赖、提取深层特征；
       （2） 分类性能优势：提高分类准确率、增强模型鲁棒性、改善泛化能力；
       （3）模型效率优势：共享特征表示、减少参数量、提高训练效率。

2.1 入侵检测系统
2.1.1 入侵检测原理
    入侵检测系统（IDS，Intrusion Detection System）一种通过收集和分析被保护系统信
息,从而发现入侵的技术系统[15]。其核心目标是识别未经授权的访问、恶意行为或违反安
全策略的活动，并发出警报，帮助管理员及时响应。
    入侵检测可以根据检测原理分为三种类型：异常检测、误用检测和混合检测。
    异常检测是把当前网络的行为和系统正常的行为做对比。如果在对比过程中，发现
两者之间的差距大于设定的阈值，就说明系统出现异常或被入侵。异常检测可以识别未
知的攻击，但问题在于如何准确区分正常流量和异常行为，以及如何设置合适的阈值。
目前还没有统一的标准，这导致该方法的误报率较高。
    误用检测是根据已知的攻击特征，将异常流量和正常流量区分开来。误用检测能够
明确标识入侵类型，具有较高的准确性和较低的误报率。然而，这种方法对于未知攻击
的识别能力较差。
    混合入侵检测是结合了异常检测和误用检测的优点。它不仅能够识别未知的攻击，
还能提高准确性并减少误报。因此，混合入侵检测是目前比较常用的方法。
2.1.2 入侵监测系统分类

          。基于主机的 IDS 监控主机或服务器上的活动，来检测潜在的攻击。它可以发
现内部的问题，误报率较低，但无法检测网络攻击，覆盖范围有限，配置也较为复杂。
相比之下，基于网络的 IDS 监控网络上的数据流量来检测潜在的攻击，通常部署在网络
的入口点。因此，选择适合的 IDS 需要根据具体的网络环境和安全需求来决定[16]。
    总结来说，本课题中提到的入侵检测方法，若根据数据来源来划分，是基于网络的
入侵检测；如果按检测方法来分类，则是基于异常的入侵检测。

2.2.2 入侵检测系统流程
   入侵检测系统的工作流程包括三个主要步骤，分别为数据预处理，特征建模，分类器
分类。
   数据预处理有两部分工作。首先是通过属性映射，将不同类型的特征转换为数字型
值，这样便于算法处理。其次，消除不同属性值之间的量纲差异，通常通过数据归一化
来实现[17]。
   特征建模是对数据特征进行建模，从网络连接数据中提取特征。
   分类器分类就是使用分类器对数据进行分类，将数据分为正常数据和不同类型的攻
击数据，并输出分类结果。
   设计入侵检测系统时，需要确保系统具备以下特性，可靠性、可用性、可验证性和
准确性。这样，系统能够高效且及时地识别出网络或系统中的异常行为，并能够做出适
当的响应。

2.3 入侵检测系统需求分析
2.3.1 现有入侵检测系统的局限性
    传统的入侵检测系统主要基于规则引擎，通过预设的规则来检测网络流量和系统行
为中的异常情况。然而，随着攻击手段的日益复杂，规则引擎很难准确地识别出新的攻
击方式，导致误报率较高。例如，当网络中出现合法的高流量行为（如大型文件下载或
在线视频观看）时，传统 IDS 可能会将其误判为 DDoS 攻击。
    规则引擎需要定期更新规则库，以适应不断出现的新攻击手段。但在实际应用中，
由于规则更新的速度相对较慢，无法及时应对新兴的攻击方式。例如，当一种新的恶意
软件出现并开始传播时，传统的 IDS 可能需要数天甚至数周的时间来更新规则库，从而
在这段时间内无法有效地检测到该恶意软件的攻击。
    传统的入侵检测系统主要依赖于已知攻击模式的签名匹配，对于未知攻击或零日攻
击（Zero-day Attack，这是指软件漏洞被发现后，在软件厂商发布补丁之前被攻击者利用
的攻击）几乎无能为力。
2.3.2 引入机器学习算法的可行性分析
    通过引入机器学习算法，入侵检测系统能自动学习网络流量和系统行为的正常模式
，从而更准确地识别出异常行为[18]。机器学习算法可以从大量的数据中提取特征，发现
隐藏在数据中的规律，与传统的规则引擎相比，可以显著降低误报率和漏报率。
    机器学习模型可以快速适应新的攻击方式，通过对网络数据的不断学习和更新，及
时检测到未知攻击或零日攻击。这使得入侵检测系统能够更有效地保护网络和计算机系
统免受新出现的威胁。
    传统的入侵检测系统需要大量的人力进行规则的编写、维护和更新。本课题的系统
可以通过自动学习和更新模型，减少对人工干预的依赖，从而降低企业的人力成本。

2.4 相关算法理论
2.4.1 MLP 算法
    多层感知机（MLP） 是一种基础的人工神经网络（ANN，Artificial Neural Network
）结构，主要用于分类和回归任务。它采用全连接层结构，每一层的所有神经元与下一
层的所有神经元相连，通过激活函数（如 Sigmoid、ReLU）引入非线性，能够拟合复杂
的非线性关系。训练时通常采用反向传播算法，根据损失函数（如均方误差、交叉熵）
的梯度来更新权重。

2.4.2 L-SVM 算法
    线性支持向量机（L-SVM，Line-Support Vector Machine）作为经典的二分类算法，
其核心机制可概括为：在特征维度空间中构建最优线性决策边界。该算法接收带有类别
标签的训练样本集（由特征向量及对应分类标识组成），通过优化间隔最大化原则确定
分类超平面。其本质目标是寻找具备最大分类间隔的线性判别面，使不同类别数据点在
特征空间中形成最宽泛的隔离带。这一过程通过支持向量驱动完成——仅依赖距离决策
面最近的少量关键样本点（即支持向量）确定超平面参数，这些边界样本对分类规则的
构建起决定性作用。相比传统分类模型，L-SVM通过结构风险最小化策略，在模型复杂
度与泛化性能间实现更优平衡，尤其适用于中小规模数据集的精确分类任务。

     长短期记忆网络（LSTM，Long Short-Term Memory）是一种特殊的递归神经网络（
RNN，Recurrent Neural Network），用于处理和预测时序数据[20]。LSTM的核心优势在于

     NSL-KDD 数据集从不一致的值（异常值）中过滤出来，这是数据规范化之前的一个

指的是将数据的每个特征减去均值，然后除以标准差，使得数据的分布具有零均值和单
位方差[21]。本课题使用Z-score标准化方法来处理，其公式为式（3.1）：

                Xstandardized   （x   μ）⁄σ
                                                   ）
     其中：X 是原始数据，μ 是数据的均值，σ 是数据的标准差，对于缺失值使用0填充
。
     本课题并没有显式地进行异常值检测和删除，因为使用Z-score标准化，这本身就能
在一定程度上处理异常值的影响。通过对于缺失值统一用0填充，对于数值型特征，保留
了原始数据，没有进行异常值过滤，使得标准化后的数据有以下特点：所有数值型特征
的均值为0；标准差为1；数据分布更加集中，有利于模型训练；不同特征之间的尺度差
异被消除。
     数据预处理步骤中，数据标准化化对实验有着重要意义：可以提升深度学习模型的
收敛速度，节省网络学习的计算资源和时间成本；可以在一定程度上避免因奇异数据引
起的无法收敛的问题；可以在一定程度上避免因数据量级差别大而使部分特征被掩盖的
问题。

3.3.3 数据划分
     数据划分为机器学习中的一个重要概念，指的是将原始数据集按照一定比例分成若
干子集的过程。通常情况下，数据会被划分为三个主要部分：训练集（Training Set）、验
证集（Validation Set）和测试集（Test Set）。这种划分的主要目的是为了确保模型能够
有效地泛化到未见过的数据。训练集用于构建和调整模型参数的部分，使模型能够从数
据中学习模式。验证集用于调参或选择最佳模型版本的部分，在此阶段可以优化超参数
并防止过拟合。测试集用于最终评估模型性能的部分，提供关于模型在新数据上的表现
的信息。
     数据划分可以防止过拟合，通过分离出独立的测试集，可以在不干扰模型训练的情
况下评估其真实性能。这样能有效检测是否存在过拟合现象，即模型仅对训练数据表现
出色但在未知数据上效果较差的情况。也可以提高模型可靠性，合理的数据划分有助于
提高模型预测能力的一致性和稳定性。当模型经过充分训练并在验证集中进行了适当调
节后，再利用完全隔离的测试集来衡量其实际效能，则可获得更可靠的评价指标。还可
以保证资源高效分配，对于大规模数据集而言，合理规划各阶段所需样本量不仅节约计
算资源还能加快实验进程。例如设置较小比例作为验证/测试用途即可满足需求而不必浪
费过多实例参与非必要环节。
     本课题采用 10 折交叉验证法评估模型性能。该方法将完整数据集随机均分为十组
等容量子集，每轮迭代选取一组作为独立测试集，其余九组合并构建训练集。通过十轮
循环验证，确保每个样本均参与过测试过程，最终整合十次评估结果计算综合指标。这
种策略有效规避了单次划分可能引入的样本偏差，通过多轮迭代平均更客观反映模型泛
化能力，尤其适用于中小规模数据集的稳定性能评估。

3.4.3 知识蒸馏架构
     在模型构建部分，入侵检测系统采用知识蒸馏（Knowledge Distillation）架构，包含

习中，它被用作模型压缩和知识转移的一种形式，尤其适用于大规模深度神经网络。知
识蒸馏的本质是知识迁移，模仿教师模型的输出分布，使学生模型继承其泛化能力与推
理逻辑。

3.5 模型训练过程
  在训练过程中，首先加载并处理数据集。数据经过标签编码和特征选择，保留最有助
于分类的特征。数据集被划分为训练集、验证集和测试集，且所有特征都进行了标准化处
理，以确保模型的训练更加稳定。训练数据和验证数据通过 PyTorch 的 DataLoader 进行批
次加载。
  训练中采用了 Adam 优化器及 BCELoss。该自适应学习率算法可加速训练并防止梯
度异常，确保模型稳定收敛[22]。BCELoss 则适用于二分类任务，用于计算模型输出与实
际标签之间的差异。每一轮训练过程中，模型会根据训练数据进行前向传播、计算损失
、进行反向传播更新网络参数。每个 epoch 的训练过程中，模型会根据训练集和验证集
的损失情况进行调整。模型训练时会输出每个 batch 的训练损失，并且在每个 epoch 结
束后评估验证集的表现。通过在验证集上的损失和准确率，能够监控模型是否出现过拟
合。训练结束后，模型在测试集上的性能得到评估，计算并输出准确率。最终，训练好
的模型会被保存，以便后续使用和推理。

4.3.5 模型调优
     通过调整不同的参数值，达到训练调优的目的，通过调整不同的指标来对模型进行
持续优化。
     学习率为控制参数更新的步长，影响模型的收敛速度和稳定性。较小的学习率可能
导致收敛速度慢，而较大的学习率可能导致训练不稳定，甚至使模型无法收敛。
     权重衰减是正则化参数，防止模型过拟合。它通过对模型的权重施加惩罚，促使模
型学到较为简单的结构，从而避免过拟合。
     批量大小是每次训练时输入给模型的样本数。较小的批量大小使得每次参数更新更
加频繁，适应性强，但训练速度较慢；较大的批量大小则能更稳定地估计梯度，但训练
过程中可能会出现内存问题。总而言之，它可以影响训练速度和梯度更新的稳定性。
     训练轮数是训练轮数是整个训练集被模型学习的次数，决定模型训练的充分程。训
练轮数较少可能导致模型未学到足够的特征，过多可能导致过拟合。
     Alpha通常是模型中某些正则化项或调整机制的参数，在本课题中为LSTM中的权重
衰减或其他层的超参数。Alpha的调节可能影响模型的稳定性和正则化效果。调整它有助
于模型的细节优化。

通过调节温度，可以调整模型输出的分布，使得输出更加平滑。

                第五章 总结与展望
5.1 系统成果总结
    随着网络攻击手段的多样化和复杂化，传统的入侵检测方法在应对新型威胁时逐渐
暴露出局限性。本课题针对这一问题，设计并实现了一种基于LSTM和自编码器结合的入
侵检测系统。通过将LSTM对时序数据的处理能力与自编码器的特征提取功能相结合，系
统能够自动从网络流量中学习关键特征，并利用多任务学习框架提升模型的分类性能和
泛化能力。
    在实验阶段，系统首先筛选出对分类贡献最大的特征，再对数据进行标准化处理和
分批次训练。采用Adam优化器和交叉熵损失函数进行模型训练后，系统在测试集上表现
出了较高的检测准确率，验证了设计的有效性。相较于传统方法，本课题的创新点主要
体现在以下三个方面：
    特征提取更智能，模型能自动从原始数据中学习时序依赖和深层特征，减少了对人
工特征工程的依赖；
    分类性能更优，结合LSTM和自编码器的多任务学习框架，在提升检测精度的同时增
强了模型的稳定性；
    训练效率更高，通过调整共享编码器参数，减少了模型的计算复杂度，训练速度显
著提升。
    然而，系统仍存在一些不足之处：首先，实验仅基于公开数据集进行验证，实际网
络环境中的流量可能更加复杂；其次，模型对硬件资源的要求较高，实时检测的响应速
度有待优化；最后，模型的可解释性仍需加强，以便在实际部署时更好地辅助安全分析
。

5.2 未来工作展望
    针对当前系统的不足，未来的改进方向可以从以下几个方面展开：
    提升模型的适用性，例如在更多实际网络环境中进行测试，收集不同场景下的流量
数据，增强模型的泛化能力，尝试将模型与其他轻量级算法（如决策树、随机森林）结
合，降低对计算资源的需求，提高实时检测效率。
    优化器的选择，因为优化器控制着模型如何更新权重。常见的优化器有 SGD（随机
梯度下降）、Adam。Adam（自适应矩估计）结合了动量和自适应学习率的优点，适用于
大多数任务，尤其是在处理具有稀疏梯度的任务时，表现良好。相比于传统的SGD，

Adam在训练过程中能自动调整每个参数的学习率，通常能加速收敛 。SGD，简单有效，
适用于很多标准任务，但可能需要更多的调整来避免震荡和局部最优解。
     模型正则化（Regularization），正则化方法通过对模型施加额外的约束，避免模型在
训练集上表现过好而在验证集上性能较差，从而减轻过拟合的风险。
     模型架构改进，例如对于更复杂的任务，可以尝试增加网络的层数，使其能够学习
到更复杂的特征。然而，层数过多也可能导致过拟合 。根据任务的不同，选择合适的激
活函数也是优化的一部分。例如，ReLU、Leaky ReLU、Swish等激活函数，能更有效地
推动网络训练。
