# 期货智能体模拟系统 (Futures Agent Simulation System)

多智能体期货交易模拟系统：4种策略智能体在36个真实市场情景中进行决策演练，结合记忆检索和LLM真实决策，展示策略迭代与评分机制。

## 项目概述

这是一个多智能体期货交易模拟系统，通过模拟不同类型的交易策略智能体，在真实市场环境中进行决策演练。系统核心展示了：

- **真实历史价格数据**：黄金、WTI原油、大豆的月度历史价格（覆盖1833年-2026年）
- **36个历史情景**：覆盖2016-2026年重大市场事件（避险冲击、贸易战、疫情、地缘冲突等）
- **4种智能体策略**：保守型、均衡型、激进型、记忆审计
- **LLM真实决策**：支持通过SiliconFlow API使用大语言模型进行真实买卖决策
- **记忆检索机制**：智能体检索历史相似案例辅助决策
- **策略评分系统**：基于LLM真实决策或历史回放的得分计算

```
│  ┌──────────────┐  ┌──────────────┐  ┌───────────────┐ │

│  │ 场景引擎     │  │ SiliconFlow  │  │  历史价格     │ │
│  └──────────────┘  └──────────────┘  └───────────────┘ │
└─────────────────────────────────────────────────────────┘
```

### 核心流程

```
[场景切换] → [智能体工作站循环] → [LLM决策/预设动作] → [得分计算] → [状态广播]
     ↑                                                            │
     └──────────────────── 90秒(LLM模式) / 4.5秒(模拟模式) ←───────┘
```

1. **场景切换**：系统按时间线切换到下一个历史情景（如"2020-04 疫情错位"）
2. **工作站循环**：4个智能体依次经过6个工作站（资讯采集→记忆检索→价格趋势→风险控制→辩论→交易执行）
3. **决策生成**：
   - **LLM模式**：调用SiliconFlow API，90秒后返回真实买卖决策
   - **模拟模式**：使用预设的ACTIONS_BY_AGENT动作序列（即时得分）
4. **得分计算**：根据决策动作（买入/卖出/持有）和价格变化计算得分
5. **状态广播**：通过WebSocket推送完整状态或增量patch到前端

## 智能体策略

系统包含4个不同风格的交易智能体：

### 1. 保守型 (Conservative Hedger)
- **风险偏好**：低
- **偏好品种**：黄金
- **策略特点**：
  - 先保本金，至少等待两个信号互相确认后才逐步建仓
  - 仓位控制严格，回撤容忍度低
  - 在不确定市场环境下倾向于持有现金

### 2. 均衡型 (Balanced Strategist)
- **风险偏好**：中
- **偏好品种**：原油
- **策略特点**：
  - 综合宏观资讯、价格趋势和回撤压力
  - 偏好分批进出，不追求极端收益
  - 在趋势明确时适度加大仓位

### 3. 激进型 (Aggressive Breakout)
- **风险偏好**：高
- **偏好品种**：大豆
- **策略特点**：
  - 当动量和资讯共振时提前行动
  - 接受更大的阶段性回撤以换取更高收益
  - 在市场转折点敢于重仓

### 4. 记忆审计 (Memory Auditor)
- **风险偏好**：中低
- **偏好品种**：黄金
- **策略特点**：
  - 质疑拥挤交易，检索相似失败案例
  - 在每一季后修正策略
  - 通过历史教训避免重复错误

## 智能体工作站

每个智能体在决策过程中依次经过6个工作站：

| 序号 | 工作站 | 功能 |
|------|--------|------|
| 1 | 资讯采集台 | 抓取市场新闻和宏观事件 |
| 2 | 记忆档案馆 | 检索历史相似案例和教训 |
| 3 | 价格趋势墙 | 读取近期价格趋势和技术指标 |
| 4 | 风险控制室 | 检查回撤边界和仓位限制 |
| 5 | 智能体辩论场 | 多智能体辩论信号质量 |
| 6 | 交易执行门 | 生成最终交易指令（买/卖/持有） |

## 得分计算机制

### 两种得分模式

#### 模式1：LLM真实决策得分（推荐）
- **触发条件**：启动时设置 `FUTURES_AGENT_TRADING_LLM=1` 且配置 `SILICONFLOW_API_KEY`
- **工作流程**：
  1. 场景切换后，智能体等待LLM决策（约90秒）
  2. LLM分析当前情景的新闻、价格、记忆后返回真实决策（BUY/SELL/HOLD）
  3. 系统根据LLM的实际动作 + 历史价格变化计算得分
  4. 更新UI显示基于LLM真实决策的得分和排名
- **得分计算**：
  ```
  得分 = f(动作方向, 当前价格, 下一期价格, 仓位规模)
  - BUY + 价格上涨 → 正得分
  - SELL + 价格下跌 → 正得分
  - HOLD → 中性得分
  - 反向操作 → 负得分
  ```

#### 模式2：预设动作模拟得分
- **触发条件**：未配置LLM或 `FUTURES_AGENT_TRADING_LLM=0`
- **工作流程**：
  1. 场景切换后，立即使用预设的ACTIONS_BY_AGENT动作序列
  2. 根据预设动作（买/卖/持有）和真实历史价格计算得分
  3. 即时显示得分和排名
- **说明**：此模式用于离线模拟，得分基于预设动作而非真实AI决策

### 评分指标

每个智能体的评分包含：
- **总得分 (totalScore)**：训练段和测试段的综合得分（去均值化）
- **训练得分 (trainingScore)**：前N个情景的表现
- **测试得分 (testScore)**：后N个情景的表现（避免过拟合）
- **最大回撤 (maxDrawdown)**：最大连续亏损幅度
- **胜率 (hitRate)**：正确方向判断的百分比
- **建议状态**：采纳(adopt) / 观察(watch) / 淘汰(remove)

## 扩展开发

### 添加新情景

在 `adapter/tradingGameDemo.js` 的 `ROUNDS` 数组中添加新对象：

```javascript
{
  date: 'YYYY-MM-DD',
  regime: '市场状态描述',
  prices: { gold: XXXX, soybean: XXXX, crude_oil: XX.X },
  news: ['新闻1', '新闻2', '新闻3'],
  memory: ['历史记忆1', '历史记忆2', '历史记忆3'],
  scoreboard: { conservative: X.X, balanced: X.X, aggressive: X.X, auditor: X.X }
}
```

同时更新 `ACTIONS_BY_AGENT` 数组，为每个智能体添加对应动作。

### 添加新智能体

1. 在 `AGENT_IDS` 中添加ID
2. 在 `AGENT_PROFILES` 中配置画像
3. 在 `ACTIONS_BY_AGENT` 中添加动作序列

### 替换为日频数据

1. 保留 `LocalDataLoader` 接口，替换底层数据为日频期货数据
2. 新增新闻RAG数据层，保证智能体只能读取当前交易日前已发生的资讯
3. 让每轮智能体输出结构化动作：`BUY`、`SELL`、`HOLD`、品种、仓位、理由、证据、策略补丁
4. 评分层继续使用固定测试段，避免自我迭代时把测试集信息泄漏进训练

## 常见问题

**Q: 时间跳得太快怎么办？**

A: 系统每4.5秒切换一个情景（模拟模式）或90秒（LLM模式）。当前36个情景覆盖约10年，每个情景间隔约3-6个月。如需更慢，可以在 `server/index.js` 中调整 `tickMs` 参数。

**Q: 得分是真实的还是预设的？**

A: 取决于配置。启用LLM (`FUTURES_AGENT_TRADING_LLM=1`) 时，得分基于LLM真实决策；未启用时，使用预设动作序列计算模拟得分。

**Q: LLM决策失败怎么办？**

A: 系统会自动fallback到模型链中的下一个模型。如果所有模型都失败，会使用本地回退策略。

**Q: 如何查看历史事件？**

A: 点击事件列表中的历史事件，系统会显示当时的交易状态、得分和排名，并标注"（历史）"标记。
