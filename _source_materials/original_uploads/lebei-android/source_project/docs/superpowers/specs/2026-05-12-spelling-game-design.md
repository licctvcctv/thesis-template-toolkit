# 限时拼写游戏设计

## 背景

任务书要求学习激励包含排行榜、积分、游戏。现有 App 已有积分和排行榜，`feature/review-weight` 分支已补齐拼写复习与 0-6 权重机制，因此游戏不需要新增后端排行榜，只需要把“限时拼写”作为二级页面接入现有积分体系。

## 目标

新增一个“限时拼写挑战”页面：用户在倒计时内根据释义和音标输入英文单词，拼对一个加 1 分，并调用现有 `recordStudyWord` 接口让服务端积分 +1。游戏结束后展示本局得分和正确数，用户可以再来一局或返回。

## 范围

- 在学习统计页增加“限时拼写挑战”入口。
- 新增 Android Activity 承载游戏，不新增底部导航项。
- 单词来源优先取当前到期复习词；不足时从已学习词中补齐；仍不足时提示先学习单词。
- 拼写判定复用 `WordReviewPolicy.spellingsMatch`，保证和复习页一致。
- 正确拼写后复用权重规则：权重 +1，上限 6，并更新下次复习时间、复习次数。
- 正确拼写才加本局分数和服务端积分；错误仅显示正确拼写并切换下一题。

## 非目标

- 不新增服务端接口。
- 不新增单独游戏排行榜。
- 不改 Android SDK、本地 `local.properties` 或开发机路径。

## 交互

默认倒计时为 60 秒。页面顶部展示剩余时间和本局得分；中部展示中文释义、音标和当前进度；底部为拼写输入框、提交按钮、跳过按钮。时间结束或题库用完后进入结果状态，输入区隐藏，显示得分并提供“再来一局”“查看排行榜”。

## 错误处理

- 未登录：入口处提示先登录，不进入游戏。
- 无可用单词：游戏页显示空状态，不崩溃。
- 积分同步失败：本地游戏继续，提示“积分稍后同步失败”，不影响下一题。

## 测试

核心判题与计分抽到 `SpellingGamePolicy` 做 JUnit 单测：正确答案加 1 分、错误不加分、已答题数递增、倒计时结束判定。Android UI 受当前机器无 SDK 限制，只做代码静态检查和可运行的纯 Java 单测。
