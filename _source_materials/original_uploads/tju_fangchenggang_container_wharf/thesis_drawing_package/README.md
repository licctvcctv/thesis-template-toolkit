# 论文图纸支撑包目录说明

## 目录

- `01_final_dwgs/`
  - 最终五张 DWG 图纸和五图 zip 成果包。
- `02_preview_png/`
  - 五张 300 dpi 高清 PNG 预览图，适合论文写作前快速查看图面和放大核对标注。
- `03_preview_pdf/`
  - AutoCAD 高质量 PDF 出图文件。
- `04_source_code/`
  - 本次生成图纸使用的 Python/AutoCAD COM 源码。
- `05_reference_supplement/`
  - S-02 沉箱断面及 A-A 平面补充参考资料，包括原始 DWG、截图和脚本。
- `06_design_notes/`
  - 根据绘图脚本和图纸整理出的设计规格摘录，可作为论文写作参数索引。

## 建议使用方式

1. 先看 `02_preview_png/`，确认每张图表达内容。
2. 写论文参数时查 `06_design_notes/drawing_design_specifications.md`。
3. 需要核对来源和绘图逻辑时看 `04_source_code/`。
4. 需要说明 S-02 断面来源时看 `05_reference_supplement/`。
