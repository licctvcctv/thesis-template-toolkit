# 期货智能体模拟系统

多智能体期货交易模拟：4 种策略智能体在 36 个历史情景中决策，支持 DeepSeek 真实 LLM 决策或本地预设回放，含记忆检索、辩论、评分与 Prompt 自进化。

**环境要求：** Node.js >= 18

## 安装依赖

```bash
npm install
cp .env.example .env
```

Windows PowerShell 可复制环境文件：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`，填入 `DEEPSEEK_API_KEY`（启用 LLM 时必需）。

## 启动服务

```bash
npm start
```

浏览器访问：http://127.0.0.1:3102/

## 停止服务（释放 3102 端口）

关闭浏览器不会结束 Node 进程。若重启时提示端口占用，在 PowerShell 执行：

```powershell
Stop-Process -Id (Get-NetTCPConnection -LocalPort 3102).OwningProcess -Force -ErrorAction SilentlyContinue
```

## 启用 LLM 真实决策

在 `.env` 中设置：

```env
DEEPSEEK_API_KEY=你的密钥
FUTURES_AGENT_TRADING_LLM=1
```

然后重新执行上面的 `npm start`。每轮约 90 秒；完整 36 轮运行记录写入 `runs/<runId>/`。

未配置 LLM 时使用本地预设（`ACTIONS_BY_AGENT` + `COMMODITIES_BY_AGENT`），约 4.5 秒一轮。

## 项目介绍

| 模块 | 说明 |
|------|------|
| 商品 | 黄金期货、原油期货、大豆期货（真实月度历史价格） |
| 智能体 | 保守型、均衡型、激进型、记忆审计 |
| 流程 | 资讯 → 记忆 → 价格 → 风控 → 辩论 → 执行 |
| 训练 / 测试 | 前 6 轮训练（Prompt 可进化），后 30 轮测试（Prompt 冻结） |
| 前端 | 总览、智能体、行情、工作站、策略评估、运行日志 |
| 后端 | Express + WebSocket + `adapter/simulationEngine.js` |

### 架构

```
前端 (原生 JS)  ←WebSocket→  server/index.js
                              ├── simulationEngine.js
                              ├── llmClient.js (DeepSeek)
                              └── localDataLoader.js → data/
```

### 四种智能体

- **保守型**：偏好黄金，低回撤，双信号确认后建仓
- **均衡型**：多因子平衡，分批进出
- **激进型**：动量与资讯共振时提前行动
- **记忆审计**：检索历史失败案例，在辩论后对同业观点审计

每轮每个智能体在三种商品中择一，输出 **买入 / 卖出 / 观望** 之一。

### 得分说明

- **LLM 模式**：按模型真实决策 + 历史价格变化累计评分
- **本地模拟**：按 `adapter/simulationEngine.js` 中预设动作与品种序列评分
- 指标含总得分、训练段 / 测试段得分、最大回撤、胜率（相对 alpha，用于排名与 Prompt 参考）

### 主要环境变量

| 变量 | 说明 | 默认 |
|------|------|------|
| `PORT` | 服务端口 | 3102 |
| `DEEPSEEK_API_KEY` | DeepSeek API 密钥 | - |
| `FUTURES_AGENT_TRADING_LLM` | 1=LLM 决策，0=本地预设 | 见 `.env.example` |
| `FUTURES_AGENT_RUN_RECORD` | LLM 运行是否写入 `runs/` | 1 |
| `FUTURES_AGENT_TRADING_DEMO` | 启用交易模拟 | 1 |

### 项目结构

```
adapter/          仿真引擎、36 轮情景、数据适配
server/           HTTP/WebSocket、LLM 客户端、运行录制
frontend/         界面与组件
data/             commodities-historical.json
runs/             LLM 运行输出（自动生成）
scripts/          商品数据下载与处理
```

LLM 运行结束后，`runs/<runId>/preset-export.json` 中的 `suggestedPresetActions` / `suggestedPresetCommodities` 可回写至 `simulationEngine.js` 更新本地预设。
